# Aha! website

The landing page for **Aha! Your private agent**, published with GitHub Pages from `main`.

- `index.html`: the page (a self-contained export; edit the copy in the `__bundler/template` block, or
  re-export it from the design tool).
- Don't claim more than the product does: check claims against the code in aha-local-llm and aha-gateway.

The product itself: [aha-local-llm](https://github.com/axxlabs/aha-local-llm) (runs on your computer) and
[aha-gateway](https://github.com/axxlabs/aha-gateway) (relays messages, keeps nothing).
